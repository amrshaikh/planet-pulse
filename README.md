# 🌿 PlanetPulse

**Fluid atmospheric intelligence.**

PlanetPulse is a mindful, AI-powered environmental dashboard built for the Octoverse Hackathon. It transforms complex, scattered atmospheric data into clear, actionable insights wrapped in a calming **"Organic Glass"** interface.

---

## 🚀 Live Demo
👉 https://theplanetpulse.netlify.app/

---

## ✨ Features

### 🌍 Live Telemetry
Real-time tracking for:
- Air Quality Index (AQI)
- Temperature
- Humidity
- Max UV

### 🌫️ Pollutant Breakdown
Granular, visual progress bars for:
- PM2.5
- PM10
- Ozone (O₃)
- Carbon Monoxide (CO)

### 🤖 The Gemini Protocol
Powered by **Google Gemini AI**:
- Generates an objective synopsis
- Provides an actionable health checklist
- Delivers targeted eco-advice

### 📊 24-Hour Flow
Smooth, liquid charts (powered by **Chart.js**) visualizing:
- Temperature trends
- AQI trends (next 24 hours)

### 🎨 Organic Glass UI
- Fully responsive design
- Glassmorphism-inspired interface
- Dynamic **Dawn 🌅 / Dusk 🌙 themes**
- Animated ambient orbs
